وب‌سایت هیئت روضةالکریم
=========================

اجرا:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) روی index.html دوبار کلیک کنید؛ سایت در مرورگر باز می‌شود.
3) برای ویرایش متن‌ها، index.html را با VS Code یا Notepad++ باز کنید.
4) برای تغییر رنگ و ظاهر، style.css را ویرایش کنید.

ساختار:
- index.html : متن‌ها و ساختار سایت
- style.css  : طراحی و واکنش‌گرایی موبایل
- script.js  : منوی موبایل

نکته:
- سایت به‌صورت استاتیک ساخته شده و برای پیش‌نمایش آفلاین قابل اجراست.
- فونت آنلاین در صورت دسترسی به اینترنت بارگذاری می‌شود؛ در غیر این صورت فونت جایگزین سیستم نمایش داده می‌شود.
- برنامه‌های مراسم به‌صورت نمونه/قابل ویرایش درج شده‌اند و تاریخ ساختگی ندارند.
- نشانی و کانال ایتا در فایل index.html قابل تغییر است.

انتشار رایگان:
می‌توانید فایل‌ها را در یک مخزن GitHub قرار دهید و از بخش Settings > Pages سایت را منتشر کنید.
راهنمای رسمی: https://docs.github.com/en/pages
